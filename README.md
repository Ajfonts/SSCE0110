Desarrollador Android (Kotlin/Jetpack Compose), especialista en seguridad informática y creador del proyecto *GuardianOS Shield*. ## 🚀 Objetivo Profesional
Aplicar las metodologías activas (ABP, Flipped Classroom, Gamificación con CTFs) y las mejores prácticas de seguridad (ISO 27001, hardening, privacidad por diseño) para formar a la próxima generación de profesionales de la ciberseguridad en Andalucía y España.
